# JobMarketAI

JobMarketAI is a data science project that analyzes global job market trends, identifies in-demand skills, and predicts salaries using machine learning. The system provides an interactive dashboard that helps users explore job demand, salary distributions, and skill requirements across different roles and locations.

## Project Overview

The goal of this project is to build a job market intelligence platform that helps users understand:

- Which skills are most demanded in the job market
- Which roles have the highest salaries
- Salary differences by location and experience level
- Career skill gaps for specific job roles

The project combines data analysis, machine learning, and interactive visualization to provide insights into job market trends.

## Features

### Job Market Dataset Analysis
The system analyzes job posting data containing job titles, locations, salaries, and required skills.

### Skill Demand Analysis
Extracts skills from job descriptions and identifies the most demanded technologies.

### Salary Insights
Provides salary analysis including:

- Salary distribution
- Salary by job role
- Salary by experience level
- Salary by location

### Salary Prediction Model
Uses a machine learning model to estimate salaries based on:

- job title
- location
- experience level

### Skill Gap Analyzer
Allows users to enter their current skills and compare them with skills required for a target job role.

### Interactive Dashboard
An interactive dashboard built using Streamlit allows users to explore job market insights visually.
